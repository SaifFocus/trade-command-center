# APEX browser icon

## What will change
- Generate a compact, square angular “A” monogram tailored for tiny browser-tab and bookmark sizes.
- Use the selected dark background, neon green primary strokes, and restrained gold accents.
- Keep the existing text-only APEX header exactly as it is.
- Add the generated mark as the site favicon/NavIcon and remove any stale default icon reference.
- Publish the app after the icon is verified.

## Technical details
- Produce a high-quality source image, then export an optimized 64×64 PNG with square padding rather than distortion.
- Register the PNG in the root page metadata so browsers and bookmarks use it.
- Verify the icon loads successfully, the dashboard remains unchanged, and the published version uses the new asset.
